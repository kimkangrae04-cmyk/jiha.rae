# 지하 ♥ 래의 추억 박물관

둘이 방 코드로 접속해서, 우리 사진이 액자로 걸린 3D 박물관을 함께 걷는 웹 게임입니다.

## 플레이 방법
1. 한 사람이 **새 방 만들기** → 화면 왼쪽 위의 **방 코드**(5자리)나 **링크 복사**로 상대에게 보내기
2. 다른 사람은 코드를 입력하고 **참가** (또는 받은 링크로 바로 접속)
3. 이동: `WASD` / 방향키 (모바일은 왼쪽 아래 조이스틱)
4. 시점: 화면 드래그, 확대/축소: 마우스 휠
5. 액자 앞에서 `E` 또는 🔍 → 사진 크게 보기 → **상대에게도 보여주기**
6. `H` 또는 ♥ 버튼 → 하트 날리기

## 사진 넣는 법
1. `photos/` 폴더에 사진 파일을 올립니다 (예: `01.jpg`, `02.jpg` …)
2. `photos/photos.json`에 순서대로 적습니다.

```json
{
  "title": "지하 ♥ 래의 추억 박물관",
  "photos": [
    { "file": "photos/01.jpg", "title": "처음 만난 날", "date": "2024.03.01", "caption": "설명" }
  ]
}
```

- 사진 개수에 맞춰 전시관 길이가 자동으로 늘어나고, 왼쪽·오른쪽 벽에 번갈아 걸립니다.
- 사진 파일이 없으면 그 자리에 분홍색 임시 액자가 보입니다.
- 사진은 한 장당 2MB 이하(긴 변 2000px 정도)로 줄여서 올리면 빨리 열려요.
- ⚠️ 공개(public) 저장소라면 사진도 누구나 볼 수 있어요.

## 배포 (GitHub Pages)
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**  
잠시 뒤 `https://<아이디>.github.io/jiha.rae/` 주소로 접속할 수 있습니다.

## 기술
- [Three.js](https://threejs.org/) — 3D 렌더링
- [PeerJS](https://peerjs.com/) — WebRTC로 두 브라우저를 직접 연결 (별도 서버 없음)
- 빌드 과정 없는 순수 HTML/CSS/JS

## 로컬에서 실행
`fetch` 때문에 파일을 더블클릭하면 안 되고 간단한 서버가 필요합니다.
```bash
npx serve .        # 또는: python -m http.server
```
